# 角色设定
你是一个拥有10年经验的资深前端开发工程师，精通高保真网页复刻、原生 HTML5/CSS3 以及响应式布局设计。

# 任务目标
请帮我编写一个“京东物流（www.jdl.com）”官方网站首页的静态复刻网页。最终要求生成的代码不需要任何构建工具（如 npm/webpack），直接双击 index.html 就可以在本地浏览器中完美运行浏览。

# 技术要求（严格遵守）
1. **技术栈**：纯原生 HTML5 + CSS3 + 原生 JavaScript。
2. **样式规范**：请将 CSS 写在一个单独的 `style.css` 文件中（或使用 `<style>` 标签写在 HTML 的 head 中），推荐使用 Flexbox 和 CSS Grid 布局。
3. **响应式设计**：必须包含媒体查询（Media Queries），确保在桌面端（1440px）、平板端（768px）和移动端（375px）都有良好的显示效果。
4. **外部资源**：如果需要图标，请使用 FontAwesome 的 CDN；如果需要轮播图，可以使用 Swiper 的 CDN；如果需要字体，请使用系统默认的无衬线字体（sans-serif）。**（可选修改）**

# 页面结构要求（按顺序生成）
请按照以下逻辑分块生成首页：
1. **顶部导航栏（Header）**：包含京东物流 Logo（可用文字占位）、一级导航菜单、搜索框、登录/注册按钮。要求导航栏吸顶（sticky）。
2. **首屏 Banner 区**：全屏或半屏大图背景（使用占位图），居中的大标题、副标题和一个主要操作按钮（CTA）。需要有视觉冲击力。
3. **核心业务区**：网格布局（Grid），展示 4-6 个物流服务卡片（如：供应链、快递快运、冷链等），卡片需要有悬停放大或阴影特效。
4. **数据展示区**：横向排列的几组核心数据（如：覆盖国家数、服务客户数），带简单的数字滚动动画。
5. **底部信息栏（Footer）**：包含多列链接导航、版权信息、备案号占位。

# 素材与占位说明
由于你无法获取真实的商业图片，请统一使用带有描述性文字的占位图服务（例如 `https://placehold.co/800x400?text=JDL+Banner`），并在 CSS 中设定合适的宽高比。

# 输出要求
请将代码分块输出：
1. 首先输出完整的 `index.html` 代码。
2. 然后输出 `style.css` 的代码。
3. 最后输出 `script.js` 的代码（用于交互，如移动端菜单展开、数字动画）。
4. 在代码输出完毕后，请告诉我如何在本地创建这些文件并预览。
